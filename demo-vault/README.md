# Advanced Rename and Delete Handler demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Advanced Rename and Delete Handler](https://github.com/mnaoumov/obsidian-advanced-rename-and-delete-handler) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **Advanced Rename and Delete Handler: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `advanced-rename-and-delete-handler-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-advanced-rename-and-delete-handler/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `advanced-rename-and-delete-handler-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
